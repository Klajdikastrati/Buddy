# Buddy

Fast, mobile-first personal logger. Local-first PWA (React + Dexie), Supabase for sync.

```bash
npm install
npm run dev        # http://localhost:5173 (also on your LAN for phone testing)
npm test           # core logic tests
npm run build      # type-check + production build (dist/)
```

Start here: `docs/ROADMAP.md` (current phase), then `docs/PRODUCT.md` and `docs/ARCHITECTURE.md`.
